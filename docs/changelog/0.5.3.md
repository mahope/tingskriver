# Tingskriver 0.5.3

Ændringer siden app-v0.5.2:

## Rettet

- Tjek, at Windows-installeren kan installere, starte og afinstallere på en ren
  profil. Nye profiler får nu posten til automatisk start (#238).
- Kod de færdige optagelsesfiler parallelt, og hold langtidstesten af optagelser
  inden for tidsgrænsen (#239).

## Ændret

- Opret automatiske dev-forhåndsudgivelser hver ottende time, når main har
  ændringer, og CI er grøn (#216).
- Begræns unødvendige CI-byg, og tjek formatering af ændrede Rust-filer (#237).
- Dokumentér GPUI-komponenterne, og kræv genbrug før nye komponenter (#217).
- Kortlæg synlige funktioner, og dokumentér det resterende GPUI-arbejde (#173).
- Vælg transskriptionsmotor og styr modeller i GPUI-appen under Indstillinger > Transskription: hent med
  fremdrift og annullering, kontrolsum, status og sletning (#174).

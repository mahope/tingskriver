## Installation

Hent **Tingskriver-Setup.exe**, og kør filen. Appen installeres kun for din
bruger og kræver ikke administratorrettigheder.

Windows SmartScreen kan advare, fordi appen endnu ikke er signeret. Vælg
**Flere oplysninger → Kør alligevel**, hvis du vil fortsætte installationen.
